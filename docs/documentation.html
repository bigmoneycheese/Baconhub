BaconHub loader and supported games

Install:

loadstring(game:HttpGet("https://raw.githubusercontent.com/bigmoneycheese/Baconhub/main/main.lua"))()

The loader checks game.GameId and downloads the matching game script from the scripts folder.

BaconHub is open source so people can read the scripts, learn how features work, and build their own projects from the code.

Supported Games:

  • BBQ It
  • Demonology
  • +1 Health Per Click
  • Gun Evolution
  • Slime RNG
  • +1 Shrink per Step
  • Forsaken
  • SLAP
  • Spin a Soccer Card
  • untitled tag game

Notes:

Use the loadstring from the Download page. BaconHub automatically loads the matching supported game script.

There is no key system. The project is meant for community use, learning, and sharing working examples.
